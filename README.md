# Raw Material Accounting System in Manufacturing

Система обліку сировини на виробництві: надходження, витрати, залишки на складах і контроль використання матеріалів у виробничих процесах.

## Мета

Забезпечити прозорий облік сировини від моменту закупівлі до списання у виробництво, зменшити втрати та спростити звітність для складу й керівництва.

## Основні можливості (планується)

- Облік надходження та видачі сировини
- Залишки на складах у реальному часі
- Прив’язка матеріалів до виробничих партій / замовлень
- Звіти про витрати, дефіцит і рух сировини
- Розмежування доступу за ролями

## Потенційні ролі

| Роль | Обов’язки |
|------|-----------|
| **Адміністратор** | Керування користувачами, ролями, довідниками матеріалів і складами |
| **Складський працівник** | Приймання, видача, інвентаризація, коригування залишків |
| **Закупівлі** | Заявки на закупівлю, постачальники, контроль поставок |
| **Технолог виробництва** | Запити на сировину під партії, контроль норм витрати |
| **Бухгалтер** | Вартісний облік, звіти, списання, звірка з обліком |
| **Аналітик** | Дашборди, аналітика запасів, дефіциту та ефективності |
